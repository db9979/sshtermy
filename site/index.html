SSH terminal with an AI copilot

One small file for Windows, macOS and Linux. Connection manager, real terminal, SFTP and tunnels, plus an AI that suggests commands, works towards a goal step by step or on its own as an agent, and explains errors. Dangerous commands always wait for you.

Install

Pick your system. Every way installs the same release from GitHub.

Windows ARM64 · x64 · x86

With winget (Windows 11 and 10):

winget install db9979.sshTermy

Available as soon as the package is approved in the winget catalog.

Or download the .exe for your processor from the releases: a double-click opens sshTermy in its own window. Started from Windows Terminal it runs right there.

macOS Apple Silicon · Intel

With Homebrew:

brew tap db9979/sshtermy https://github.com/db9979/sshtermy
brew install sshtermy

Or with one line, which also creates ~/Applications/sshTermy.app (opens in its own window, no Terminal needed):

curl -fsSL https://raw.githubusercontent.com/db9979/sshtermy/main/install.sh | sh

Linux amd64 · arm64 · armhf · riscv64

Debian, Ubuntu, Raspberry Pi OS, ClockworkPi uConsole (apt):

echo "deb [trusted=yes] https://db9979.github.io/sshtermy/apt ./" | sudo tee /etc/apt/sources.list.d/sshtermy.list
sudo apt update && sudo apt install sshtermy

Homebrew and the one-line installer above work on Linux too.

Then type sshtermy. On first start you choose a master password for your encrypted store.

Tour

Unlock, pick a host, go

Your connections, passwords and keys live in an encrypted store (AES-256-GCM, Argon2id, plus DPAPI on Windows). The manager shows folders, tags and details; Enter connects. The details show load, RAM and disk of the server right away.

Ghost text and errors explained

While you type, the AI completes the line in gray; Tab accepts. After every command it offers follow-ups (Alt+1…4). When a command fails, Alt+0 asks the AI why, with the output as context, and 1…9 inserts a suggested fix.

One palette for everything

Ctrl+Space opens the command palette: frequent actions and recent connections on top, everything else sorted into folders (AI, session, search & logs, tabs & view, network, team …), typing finds it all at once. Plain text becomes a goal (Enter) or a question to the AI (Tab).

Agent mode: reach the goal on its own

In goal mode (F2) Tab switches to the agent. It runs commands, reads their output, writes scripts via SFTP and runs them, dry run first. You pick the level: Careful (default, read-only on its own), Normal (signed in as root every change asks) or Full (sudo too). Dangerous commands and anything that reads secrets always wait for you, Esc pauses, ? gives an instruction. At the end you get the complete summary: scroll it, copy it with c or read it in full with l. Any text in the panel, error messages included, can be selected with the mouse and is copied right away. With Plan first it only looks around read-only, writes a full plan, and you remove or change steps before you approve it with ⏎.

AI companion: reads along, speaks up

Alt+K picks the level. Quiet only speaks up when a command fails, a typed line is risky before you press Enter (Alt+1 swaps in the safer variant) or a command repeats. Chatty comments on every command in the sidebar (Alt+J). Coach spots what you are working towards and hands the rest to plan mode or the agent, and recaps the session when you close the tab. Limits per hour and per day, nothing sent at password prompts, and with your own AI the filters can be turned off.

Split view, tabs and workspaces

Ctrl+T shows up to six sessions in seven layouts. Drag dividers with the mouse, zoom a pane with Alt+Z, swap panes by dragging their title, and Alt+I types into all of them at once. w in the manager saves the whole arrangement as a workspace.

Features

Connection manager

Folders, tags, jump hosts, import from ~/.ssh/config, PuTTY and MobaXterm.

Forgiving

Quitting asks while connections are open, deleting offers undo for 10 s, Ctrl+T in the form tests the connection before saving, and failed connections explain in plain language what's wrong (with a key to fix it, e.g. accept a new host key after a reinstall). Simple mode hides the pro features.

Own window

No terminal needed: double-click the .exe, open the .app or run sshtermy -window. Font, Nerd Font symbols and emoji are built in, every key arrives (Alt+⏎, ⇧F-keys, Ctrl+Space), images show pixel-perfect, dropped files are uploaded, ⇧F10 opens a second window. Starts in full screen (F11 toggles; maximized or “as last time” in the settings), font size and window position are remembered. From a terminal it runs in the terminal as before.

Goal mode in daily use

? gives the AI an instruction mid-goal, ⇧S skips a step with a reason. When a command asks [Y/n] or a pager waits, the panel shows answer buttons. Files a step changes are backed up first, u restores them all; f starts a follow-up goal, earlier goals are in the history. After a connection drop ⏎ continues, and the tab shows when a goal is waiting for you.

Commands as blocks

Alt+PgUp/PgDn jumps from command to command in the scrollback. Alt+O lists the tab's commands with time, duration and result: copy exactly one output, hand it to the AI or read it in full.

Real terminal

xterm-256color, truecolor, vim, htop and tmux, scrollback (mouse wheel or ⇧+PgUp), tabs, split view, search.

Auto-reconnect

When Wi-Fi or VPN drops, the session comes back by itself, with tunnels and tmux/screen. After sleep or a network change every line is checked within seconds.

Files (F5)

SFTP over the same connection: local on the left, server on the right. e opens a server file in VS Code, Notepad++ or TextEdit, saving uploads it back. While copying: percent, MB/s, time left and a speed curve.

Files with the mouse

Double-click a file to view it right in sshTermy: colors, search, select and copy, follow like tail -f. Images and PDFs open with your default app. A single click shows a preview, right-click opens a menu with rename, permissions, copy path and cd here. Clickable path, sortable columns, Ctrl/Shift+click to mark.

Color rules

Errors red, warnings yellow, IP blue, MAC purple, switch syslog by severity; your own rules, with ! a hidden tab notifies you.

Images in the terminal

Sixel, kitty graphics and iTerm2 images (img2sixel, icat, viu, imgcat) as colored half blocks, in any terminal; pixel-perfect in kitty, Ghostty and sshTermy's own window.

Containers

Docker, Podman and Kubernetes pods in one list: shell in the container, live logs, AI log analysis.

Host overview (F6)

CPU, load, RAM, every disk and updates for servers, live Braille graphs over 5 min or 1 h with top processes; firmware, ports and VLANs for more than 35 switch, router and firewall systems, with config backup and diff.

Tunnels

-L, -R, -D (SOCKS5) and web services with one click.

Broadcast

One command or runbook on a whole group in parallel, one tile per host: green when done, red on failure, pulsing while running. Changes run on one host first as a trial run and stop after 3 failures.

Share live

A short code like 7-taube-kompass-ofen is all a colleague needs (sent as a ready-made email if you like): in the same network without a relay, otherwise through yours. They knock, you compare three check words and let them in. Without sshTermy they watch in a browser, phones too via QR code. Ends by itself, pauses at password prompts, typing only on request.

Find device

MAC or IP in, switch, port and VLAN out: sshTermy reads the MAC, ARP and LLDP tables of all switches, or only those in one folder if you look after several networks.

Network topology

LLDP/CDP neighbors become a picture with boxes, lines and port numbers, plus a Mermaid diagram; config rules check every backup.

Schedules

Broadcast or runbook at a set time on a folder, e.g. nightly show running-config on all switches. New hosts in the folder only join once you confirm them.

Password manager

Passwords and 2FA codes from 1Password, Bitwarden, KeePassXC or pass; only the reference is stored.

Network scan

Find SSH devices in a subnet and create them as connections.

Danger rules

Fixed rules mark risky commands red; they need Enter twice, also when pasted. Every connection counts as production: hold Enter until the bar is full. Turn protection off per connection only, for test and lab systems. All rule groups always apply, so a misdetected switch cannot hide erase.

docker exec without -it

docker exec gitea vi app.ini would quit at once without a terminal. On Enter sshTermy adds the missing -it (also podman, docker run, kubectl exec); the next Enter runs it.

Session log

Encrypted, searchable, with AI summary, Markdown export and an AI change report (b) for tickets or docs. An activity calendar shows which days and hours you worked.

AI log diagnosis

A selection or the last 400 lines (journalctl, show logging): situation, what stands out with timestamps, cause, commands to check.

Log view

Alt+E reads the logs of the system you are on (Linux, Windows, switches, firewalls), read-only, and shows patterns instead of lines: what is new since your last look, a timeline with reboots, updates and your own commands, hide noise per host or folder, and an AI status report from the condensed patterns only.

Log watch & folder scan

Follows the logs of open tabs in the background and reports only new or critical patterns; receives syslog from switches and firewalls. The folder scan checks every host of a folder at once (also nightly as a schedule) and shows what several hosts share. s in a switch's log view sets up syslog to sshTermy. Syslog from senders without a saved connection is dropped.

Sync

End-to-end encrypted via OneDrive, Dropbox, iCloud, Syncthing or WebDAV (Synology, Nextcloud). Keys, shell and serial port can be set per computer, schedules run only on their computer, favorites count across all.

System profile

Knows Linux distributions, macOS, Windows and network OS dialects (Aruba, Cisco, Juniper, MikroTik, FortiGate, UniFi …), so the AI suggests matching commands.

Command sets

48 command sets built in (Cisco, Arista, Aruba, Comware, Huawei, Dell, Extreme, Ruckus, Palo Alto, Sophos, FortiGate, pfSense, Proxmox …). Add your own as YAML, test it on the device or let the AI draft it, synced to your other computers; own and team sets can never weaken the built-in safety rules.

AI companion

Reads along and comments on its own: quiet (errors, risky lines before Enter, repeats), chatty (every command) or coach (spots your goal, recap with runbook). Your own AI servers, also external, can be registered. If a command from an answer card fails, the card shows the error and a corrected command; u takes it over and fixes the same mistake in the other cards.

Task across windows

Alt+V links the windows of one job (web server, database, switch). The AI sees all of them and says for each step which window it belongs in; route window by window with values carried over, plan in lanes, recap as change log. Before typing, sshTermy checks the target window (host key, prompt, system) and inserts nothing if it does not match.

Agent & plan mode

The AI works towards a goal on its own, writes and runs scripts; three levels, dangerous steps always wait for you. Plan first: review and approve the whole plan.

Split view & tabs

Seven layouts with up to six sessions, zoom, swap, type into all; tab bar with +, ×, right-click menu and tab list (Alt+T); drag tabs with the mouse, Alt+S searches all tabs. Every tab gets a colored frame, its name in the same color; red only for production. The active tab and pane are filled in their color and marked with ▶.

Bulk change

Mark several connections in the manager (Space, * for all hits) and change tags, user, protection or color in one step, move or delete them.

Note, start command, Wake-on-LAN

Per connection a note just for you, a command typed after login, and waking powered-off machines; sshTermy remembers the MAC address itself.

Telnet & serial

Telnet and USB console cables (e.g. Aruba switches), cable picked automatically, login typed for you.

Remote PowerShell

Log into Windows servers like Enter-PSSession over WinRM (NTLM or Kerberos, encrypted, or HTTPS), with history, Tab completion from the server and AI that speaks PowerShell.

Local shell

Your own PowerShell, cmd, zsh or bash as a tab (Alt+L), with AI, agent and plan mode, split view and session log; danger rules apply here too.

Pro SSH

Agent forwarding, X11 forwarding, FIDO2 security keys, Kerberos/GSSAPI, SSH certificates, persistent tmux/screen sessions. Quantum-safe key exchange (ML-KEM) where the server supports it, and a clear notice when an old device only speaks SHA-1/CBC.

Files in the terminal

tsz/trz (trzsz) through sudo su and several hops, clipboard from the server via OSC 52.

Team sharing

Encrypted .sshteam packages and team folders that keep everyone's connections up to date, without passwords.

Look & keys

26 themes with live preview, from Polar night, Synthwave and Ink to Paper and Mint, plus high contrast and color blindness, your own colors, four icon styles, every shortcut can be changed.

Tidy screen

One header line with tabs on the left and the session state on the right, a red ▲ PRODUCTION badge instead of a red bar, a function key bar at the bottom (1Help 2Goal 3AI …). The manager shows only what belongs to the selection, a folder its contents with status. Help (F1) has tabs, typing filters.

Lively interface

Connecting as a card with steps and a light sweep, tabs flash on success and errors, a card when hovering a tab, breathing online dots (only visible connections are checked) and load bars, the AI answer types out, palette matches light up, latency curve in the header, a frame gliding between split panes, dialogs with shadows and optional round corners. Full, subtle or off.

Accessible & supportable

Accessible mode without animations and with shapes instead of color only. Debug log for bug reports (--debug), saved cleaned of hosts, IPs and passwords. Adaptive frame rate when output floods, plus a performance display in the palette that rates draw time in plain words.

Screen lock

Lock now or after 5 to 60 minutes idle; sessions keep running behind the lock. Change the master password or the Windows sign-in any time.

MCP server

Claude and other AI clients use your saved connections via sshtermy mcp: read-only by default, anything else only after you confirm.

Audit log

Who did what, when and where: connections, commands, transfers, config backups. Signed and chained, so edited or deleted lines are detected.

Move to a new computer

One encrypted file holds everything: connections, keys, logs, switch backups and settings. Restore it on the new machine, the old state stays as a copy.

AI privacy

Allow all providers, only local AI on your own network, or no AI at all, globally or per connection by tag. See exactly what was last sent.

AI setup

sshTermy talks to any OpenAI-compatible endpoint (/v1/chat/completions): Ollama, vLLM, SGLang, LiteLLM, LocalAI or OpenAI itself, and also Claude (Anthropic). A local model keeps your terminal content on your own hardware.

  1. In the manager press s (AI settings).
  2. Enter the URL, e.g. http://localhost:11434/v1 for Ollama, and an API key if the endpoint needs one (stored encrypted).
  3. Ctrl+T tests the endpoint, Ctrl+L lists the models to pick from.
  4. Optional: up to three fallback providers, tried in order when the first one does not answer.
  5. Optional: a fast model on the same endpoint for ghost text, follow-ups and the companion, and house rules (e.g. “Debian 12, never suggest reboot”) that go along with every AI task; folders can add their own (e on a folder).

Every function has its own role and prompt. Requests are built so that local servers can reuse their prefix cache, ghost text sends only the last lines and answers repeated input from memory, reasoning models are asked to keep short answers short, and your own model is kept loaded while tabs are open. The AI status shows the response time per task.

The dot in the top right shows whether the AI is reachable (green, yellow when slow, red on error). Step by step, the AI only suggests and you decide what runs. In agent mode it runs commands within the level you chose; dangerous ones, and every change on production hosts and network devices, still wait for you. Passwords and secrets are removed from the context before it is sent.

Updates

A direct download or the one-line installer updates itself: sshTermy checks GitHub once a day, verifies the checksum and the signature (which also names the version) and swaps the file (F12 → u, or sshtermy --update).

Installed with a package manager, the package manager updates it:

Homebrewbrew upgrade sshtermy
aptsudo apt update && sudo apt upgrade
wingetwinget upgrade db9979.sshTermy (the built-in update works as well)

FAQ

Windows says “Windows protected your PC”

The .exe is not code-signed yet, so SmartScreen warns on the first start. Click “More info” → “Run anyway”. Installing with winget usually avoids the warning.

macOS says the app “cannot be opened”

Files downloaded with the browser get a quarantine mark. Use Homebrew or the one-line installer, or remove the mark: xattr -d com.apple.quarantine sshtermy_darwin_arm64.

Where is my data?

Windows: %APPDATA%\sshtermy, macOS: ~/Library/Application Support/sshtermy, Linux: ~/.config/sshtermy. The environment variable SSHTERMY_HOME moves it, e.g. onto a USB stick.

Which terminal should I use?

Windows Terminal on Windows, Terminal or iTerm2 on macOS, any modern terminal on Linux. Function keys and truecolor should work.

Can I switch to German?

Yes: F12 → l or palette → “Language”. On first start sshTermy follows the system language.
